Privacy Policy

Hermes LLM Wiki is a personal knowledge management application intended for private use by its owner.

Information Accessed

The application accesses Google Drive files with the account owner's authorization to store, retrieve, and organize source materials.

Data Storage and Processing

Original source files are stored in the owner's Google Drive account. Generated Markdown notes are stored on the owner's private server and synchronized through a private Git repository.

Data Sharing

The application is not intended to sell personal data or make private documents publicly accessible. Document contents may be processed by the configured AI model provider to generate knowledge-base notes.

Access Control

Access is restricted to the owner. Google Drive access can be revoked through Google Account settings.

Changes

This policy may be updated if the application's functionality or data handling changes.
